# Lluvia Estelar

Videojuego web básico hecho con HTML, CSS y JavaScript (canvas), sin dependencias.

Atrapa las estrellas (+10 puntos) y esquiva los meteoritos. Tienes 3 vidas y la dificultad aumenta con el tiempo. El récord se guarda en el navegador.

## Cómo jugar

Abre `index.html` en cualquier navegador.

- `←` / `→` o `A` / `D`: mover la nave
- `P`: pausar
- `Enter` / `Espacio`: empezar
- Móvil: arrastra el dedo sobre el juego
